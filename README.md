# porsche-gt3r-uiux
Proyek ini merupakan portofolio dan dokumentasi desain Antarmuka Pengguna (UI/UX) untuk website/aplikasi bertema otomotif performa tinggi Porsche 911 GT3 R yang dirancang menggunakan Figma. Desain ini berfokus pada estetika modern, spesifikasi performa mobil sport, sistem keranjang belanja , hingga alur transaksi yang interaktif.
